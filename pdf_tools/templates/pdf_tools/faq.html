Frequently asked questions

Is Pdfino free to use?

Yes. All core PDF tools are free to use, with generous file size limits.

How long are my files kept?

Uploaded and generated files are automatically removed from our servers a short time after processing.

Do I need to create an account?

No. All tools work without signing up. A free account simply lets you keep a history of your recent conversions.

Is my PDF to Word conversion editable?

Yes. Pdfino rebuilds the document structure - paragraphs, headings, tables and images - into a genuinely editable Word file.

What file types can I upload?

PDF for most tools, and JPG/PNG for the image-conversion tools. Every upload is validated by its actual content, not just its file extension.

Can I unlock any password-protected PDF?

The Unlock PDF tool removes a password you already know from a file you own or are authorized to access - it is not a password-cracking tool.
