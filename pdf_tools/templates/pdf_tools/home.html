Frequently asked questions

Is Pdfino free to use?

Yes. All core PDF tools are free to use, with generous file size limits.

How long are my files kept?

Uploaded and generated files are automatically removed from our servers a short time after processing - see the footer for the current retention window.

Do I need to create an account?

No. All tools work without signing up. Creating a free account simply lets you keep a history of your recent conversions.

Is my PDF to Word conversion editable?

Yes. Pdfino rebuilds the document structure - paragraphs, headings, tables and images - into a genuinely editable Word file rather than pasting plain text into a blank document.
